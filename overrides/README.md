# תיקיית Overrides (Excel / CSV ידניים)

כל קובץ `.csv` או `.xlsx` שתעלה לתיקייה זו (למעט קבצים המתחילים ב-`sample_`) יתמזג אוטומטית בסנכרון היומי עם קטלוג **DJI ישראל** ו-**בנדא סטור**.

## עמודות נתמכות
| עמודה | תיאור |
| :--- | :--- |
| `sku` | מק"ט המוצר (למיזוג מול מוצר קיים או יצירת חדש) |
| `barcode` | ברקוד EAN-13 / UPC-A / Code-128 להוספה למוצר |
| `name` | שם המוצר (משמש להתאמה אם אין מק"ט/ברקוד) |
| `brand` | מותג (ברירת מחדל: DJI) |
| `manual_price` | מחיר מבצע ידני שלנו כולל מע"מ (אופציונלי — דורס את מחיר האתר) |
| `is_on_sale` | `true` / `false` (מסמן תגית מבצע באתר) |
| `source_url` | קישור ידני למוצר (אופציונלי) |
